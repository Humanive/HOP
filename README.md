# HOP — Human Observation Protocol

> A protocol for observing humans — so that human experience can become understanding.

## Why

MCP (Model Context Protocol) standardizes how AI accesses tools and context.
ACP / A2A standardize how agents talk to each other.

But nothing standardizes how systems **observe humans** — how attention, behavior, memory, learning, and decision-making are captured, represented, and turned into understanding.

HOP fills that gap. It is the observation layer of [Humanive](https://github.com/Humanive) — living inside the core loop:

```text
Understand → Develop → Extend → Observe → Understand Better
```

HOP is what makes **Observe** a protocol, not an accident.

## What HOP Defines

- **Capture** — how human signals (behavior, reflection, context, state) are recorded with consent and dignity.
- **Represent** — how observations become structured, interpretable models of the person (goals, knowledge, patterns, blind spots).
- **Flow** — how observations feed back into understanding, development, and extension — closing the loop.

## Principles

1. The human owns their observations. Always.
2. Observation is for understanding, not surveillance.
3. Every observation must be able to answer: *what does this help the person understand or do better?*
4. Representations adapt and grow with the person over time.
5. Open, interoperable, human-centered — like any good protocol.
